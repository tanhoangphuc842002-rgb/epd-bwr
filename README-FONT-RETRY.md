# Web v61.13: phuc hoi phien cai font

Dung cho CE 2.13 v20.3-v20.7 va CE 2.9 v19.0 nhu ban web chung v61.11.
Khong can nap lai firmware. Khong mo ghi font cho thiet bi khac.

Neu cai font bi loi:

1. Cho thao tac hien tai ket thuc / bao loi (timeout xac nhan toi da 15 giay).
2. Neu BLE mat ket noi, ket noi lai dung dong ho. Khong can thao pin.
3. Vao Cap nhat phan mem > Cai du lieu tieng Viet.
4. Bam "Huy phien loi va cai lai", xac nhan dong ho dang ket noi.
5. Web huy phien chua hoan tat, doc lai trang thai va cai lai tu dau neu can.

Neu font da ghi thanh cong nhung web mat xac nhan, web kiem tra font va
khong ghi lai khi du lieu da khop. Font/cu noi dung o bank da commit van
duoc giu. Ban sao luu dung thiet bi van bat buoc truoc khi ghi lai; giu
file sao luu goc. Da bo cac nut sao luu thu cong va muc nhap file sao luu
khoi giao dien. Web van tu doc/yeu cau tai file sao luu truoc lan ghi dau.

Nut phuc hoi khong huy mot thao tac dang chay tren web, khong tu gui lai
lenh ghi sau timeout va khong reset dong ho. Neu thiet bi treo hoan toan,
khong the ket noi BLE, web khong the phuc hoi qua Bluetooth.

Tai toan bo file trong ZIP web len GitHub Pages. Khong chi tai index.html.
Chuc nang phuc hoi giu nguyen nhu v61.12. Font 2.9 co thay doi dau breve;
font 2.13 va giao thuc firmware giu nguyen. Xem README-FONT-290-BREVE.md.

Da kiem thu trinh duyet voi BLE mo phong. Can test them tren dong ho that.
